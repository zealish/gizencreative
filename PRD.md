# PRD — Gizen Creative Digital Service Platform

## Project Overview

Gizen Creative Digital Service Platform adalah website company profile yang berfungsi sebagai media presentasi layanan digital, menampilkan portofolio, paket layanan, artikel edukasi, serta menjadi sarana utama untuk menghasilkan leads melalui konsultasi dan permintaan penawaran.

---

# Objectives

- Meningkatkan kredibilitas brand Gizen Creative.
- Menampilkan layanan secara profesional.
- Memudahkan calon klien menghubungi tim.
- Menghasilkan leads melalui website.
- Mendukung pertumbuhan organic traffic melalui konten.

---

# User Roles

## Visitor

Pengunjung yang mengakses website untuk melihat informasi perusahaan, layanan, paket, portofolio, serta mengirimkan inquiry.

## Admin

Mengelola seluruh konten website, layanan, paket, artikel, portofolio, dan data leads.

## 2. Services

Website memiliki tiga kategori layanan utama.

### 2.1 Website Development

**Deskripsi:** Layanan pembuatan website profesional untuk bisnis.

**Features:**

- Company Profile Website
- Landing Page
- Business Website
- Responsive Design
- CMS Editable Content

- WhatsApp Integration
- Google Maps Integration
- Basic SEO Information

---

### 2.2 Social Media Management

**Deskripsi:** Layanan pengelolaan media sosial secara strategis.

**Features:**

- Feed Management

- Reels Management
- Caption & Hashtag
- Content Scheduling
- Monthly Performance Report

---

### 2.3 SEO Website

**Deskripsi:** Optimasi website agar memperoleh trafik organik.

**Features:**

- SEO Audit
- Keyword Research

- Technical SEO
